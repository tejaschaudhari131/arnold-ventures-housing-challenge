What moves the result

Each bar sets one published assumption to its low value and its high value, holding the others at central. The band is a seeded Monte Carlo draw from those same ranges. A close-call badge appears when the p10–p90 band crosses zero.

County and planning-region breakdown

Integer units use largest-remainder rounding, so the column adds up to the rounded state total. Connecticut is shown as the nine Census planning regions used in the 2019–2023 ACS. A star marks an imputed median value.

Tier-1 versus tier-2 cross-check

The incomplete-data estimator is run on the states that actually have parcel or land-use extracts. The gap is the error a policymaker should expect when those extracts are missing. A second column collapses counties to the state median, which is the error from ignoring price variation inside the state.

What this model cannot tell you

Assumptions

Sliders stay inside the published low-to-high band. Reset restores every assumption and turns every reform back on at full weight. The model recalculates from the equations.

Stateframe is open source under the Apache License 2.0. Structural equations live in src/model/equations.py. Default values live in config/assumptions.yaml. No machine-learning model is used. Map points are Census gazetteer interior points, not a copied basemap.
