Key points for a legislator

    Sources

    Checked against other data

    The incomplete-data estimator is compared with the parcel-informed estimate on Connecticut, Wisconsin, Utah, and Hawaii. That is a cross-check of two model runs, not a backtest against homes actually built, so this card is not labeled validated.

    Methods, tags, and downloads

    The Lab sits beside the eleven-state screening view. Equations live in src/lab/engine.py. Locked defaults live in config/lab/assumptions.yaml. Full write-up: docs/SMALL_HOMES_LAB.md.

    County shapes are U.S. Census Bureau cartographic boundary file cb_2024_us_county_5m, public domain, Douglas–Peucker simplified. See docs/DATA_PROVENANCE.md.

    Change one assumption

    Move one slider. Central values, zoning bounds, and the ACS band recompute. The p10–p90 envelope stays on the locked 2,000-draw run.
